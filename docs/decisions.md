## 결정 접수 방법

세션 중 대표가 결정 사항을 전달하면 다음 형식으로 이 파일 상단 "확정" 섹션에 기록:

```md
### YYYY-MM-DD
- **D-x-y**: [항목명] → [선택 옵션]. 근거: [1~2문장].
```

이후 관련 코드 상수(`lib/manseryeok/policy.ts` 등)에 결정을 반영 커밋.
